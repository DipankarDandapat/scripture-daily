(Google Play: `com.scripturedaily`).

## How the assets were made (and how to regenerate)

```bash
.venv/bin/python tools/marketing/make_meta_ads.py      # 75 images            (~20 s)
.venv/bin/python tools/marketing/make_meta_videos.py   # 5 videos + storyboards (~3 min)
.venv/bin/python tools/marketing/make_meta_docs.py     # copy files, CSV, logos, 08_FINAL_EXPORTS, validation
```

- One spec (`tools/marketing/campaign_spec.py`) holds every name, headline, text, CTA, composition and filename.
- App screens are **real**: screenshots of the running app (Christianity · English, Home with *and* without the Wisdom
  Tree) and wallpapers drawn by the app's own lock-screen / live-wallpaper renderers — see `play_store_creatives/README.md`.
- Only implemented features are advertised (daily verse, lock-screen verse wallpaper, live wallpaper, reminders, Wisdom
  Tree, mood check-in, Explain like I'm 5, dark theme). Always-on display is not advertised as a feature.
- Music is generated by the script (original, no licence needed). Verses are quoted exactly from the app catalogue (KJV).

## Before launch (blocking)

See `00_CAMPAIGN_STRATEGY/campaign_overview.md` → prerequisites and `tracking_strategy.md` → gaps. Most important, found
while inspecting the app code for this package:

1. **Sensitive data in Meta events.** `onboarding_completed` sends the chosen tradition (e.g. "Christianity"), several
   events send the scripture name and `mood_checked_in` sends the mood. Remove these parameters before turning on
   `meta_ads_enabled` — religion and mood are sensitive categories under Meta's terms.
2. **Meta SDK auto-initialises** (`AutoInitEnabled` / `AutoLogAppEventsEnabled` = true in the manifest), so install
   events can flow even while the server flag is off and before any consent. Decide the consent approach first.
3. `first_verse_read` is defined but never fired, so the activation event today is `onboarding_completed`.
4. The privacy policy and Play Data safety form do not yet mention the Meta SDK.
5. Replace the "Get it on Google Play" text pill with Google's official badge for paid use; confirm the Play listing is live.
