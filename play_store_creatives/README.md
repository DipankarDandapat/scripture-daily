# WisdomOne — Google Play Store creatives

Eight marketing creatives that replace raw screenshots on the Play listing, plus the feature graphic and social formats.
Everything is regenerated by one script:

```bash
python3.12 -m venv .venv && .venv/bin/pip install pillow numpy
.venv/bin/python tools/marketing/make_play_store.py          # all creatives (≈ 30 s)
.venv/bin/python tools/marketing/make_play_store.py 2 5       # only creatives 2 and 5
```

## Upload set (`06_final_exports/`)

## Where the pixels come from (no invented features)

| Folder content | Source |
|---|---|
| `01_feature_screenshots/app_*.png` | Screenshots of the running app (Android emulator, Christianity · English, SystemUI demo mode 9:41). Both Home variants are included: `app_home_no_tree_*` and `app_home_with_tree_*`. |
| `01_feature_screenshots/render_lock_*.jpg`, `render_live_*.jpg` | Drawn at 1080 × 2400 by the app’s own `LockScreenVerse` and `LiveWallpaperRenderer` code (an instrumentation run), i.e. exactly what the app puts on the lock / home screen. |
| Lock clock / date overlay | Added by `wo_kit.lockscreen()` to mimic the Android lock screen around the real wallpaper. |
| Backgrounds | The app’s bundled Christianity artwork (`android/app/src/main/assets/wallpapers/christianity`), the approved Settings landscape (`design/settings_header_landscape.jpg`) and code-generated gradients. |

Every verse shown is copied from the app catalogue (KJV): Galatians 5:22, Proverbs 12:25, Psalms 46:10, 23:1, 119:105, 30:5,
Lamentations 3:23, Philippians 4:13.

## Brand

Plum `#2D1B4E` / purple `#4B2E83`, gold `#D4A574`, parchment `#F8F2E9`. Headlines: Palatino Bold Italic (the serif-italic of the
approved "Make it Yours" design); body: Avenir Next. Phones: modern thin-bezel Android with punch-hole camera.

## Before publishing

- The **"Get it on Google Play"** pill is a text stand-in — swap in Google’s official badge (Play brand guidelines) for paid ads.
- Fonts are macOS system fonts used only to render these images; they are not redistributed.
- Play policy: no ranking / "best" claims, no price claims, nothing that implies Google endorsement — none are used here.
- Re-capture `01_feature_screenshots` if the app UI changes, then re-run the script.
